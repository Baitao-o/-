# 美食转盘 · 视觉与动效设计稿（wheel-ui）

> **状态：待 DSH 接入。** 本文档与 `web/wheel-theme.css` 配套；样式包尚未引入 `web/index.html`，以下描述的视觉效果在接入前**不会生效**。DSH 只需在 `</style>` 之后加一行 `<link rel="stylesheet" href="wheel-theme.css">`。

- 设计对象：`#wheelSection` 内的四张转盘卡（main / snack / dessert / drink）
- 硬约束：不改 `web/index.html`；不用外部 CDN 字体/图片；所有选择器限定在转盘作用域
- 基线：DSH commit `43b25ff` 的现有实现

---

## 1. 设计目标

转盘是"好玩"卖点的载体。目标三句话：

1. **一眼是麦当劳**：红 `#DA291C` / 黄 `#FFC72C` 主导，暖白纸感底，不引入违和的冷灰；
2. **四个盘各有身份**：同一家族、四种口音，凭顶条/指针/按钮的颜色就能分清是哪个品类；
3. **每次出结果都有一次可感知的小庆祝**：pop + 金环 + 彩纸，一次就够，不循环轰炸。

---

## 2. 配色方案（CSS 变量集中管理）

### 2.1 全局主题变量（定义在 `#wheelSection` 上）

| 变量 | 值 | 用途 |
|---|---|---|
| `--wt-red` | `#DA291C` | 主 CTA（结算按钮）、默认 accent |
| `--wt-red-dark` | `#b31f14` | 渐变深端 |
| `--wt-yellow` | `#FFC72C` | 金环、中奖光晕 |
| `--wt-green` | `#0f9d58` | 锁定态（沿用页面现有语义色） |
| `--wt-spin-duration` | `2900ms` | 旋转时长（与 JS `WHEEL_SPIN_MS` 绑定） |

### 2.2 四盘区分色（定义在各 `.wheel-card[data-slot]` 上）

| 盘 | accent | accent-dark | accent-soft | 依据 |
|---|---|---|---|---|
| 主食 🍔 | `#DA291C` 麦当劳红 | `#b31f14` | `#fdeceb` | 招牌牛角色，最重的一盘给主色 |
| 小吃 🍟 | `#F5A623` 琥珀 | `#c77e0a` | `#fff3dd` | 炸物金黄 |
| 甜品 🍦 | `#E8563F` 珊瑚 | `#bd3a27` | `#fdeae6` | 番茄红偏橘，与主红的区分靠明度+饱和 |
| 饮品 🥤 | `#1B7FA8` 汽水蓝 | `#145f80` | `#e3f2f9` | 唯一冷色，饮品是"解渴"角色，一眼跳出来 |

accent 用在四处：卡片顶部 4px 色条、指针、转盘外圈 2.5px 描边、单盘「转」按钮渐变。

### 2.3 扇面颜色（JS 注入，主题包不改）

盘面扇形仍是 JS 的 `conic-gradient`（`WHEEL_COLORS` 8 色循环）。主题包通过 **外圈 accent 描边 + 顶部高光/底部暗角叠加** 提质感（见 §3）。如果 DSH 愿意做可选 JS 增强，可给 `paintWheel` 传入每盘独立色板（如饮品盘偏蓝系），**非必需**，当前方案不依赖它。

## 3. 质感处理（全部纯 CSS 叠加）

| 部位 | 做法 |
|---|---|
| 扇面 | `.wheel-disc::after` 两层径向渐变：顶部 16% 处白色高光（α .40 → 0，半径 42%），底部暗角（α .16 → 0）。扇形轮廓不变，但有了"瓷盘"弧面感 |
| 外圈 | 白 6px 内圈 + accent 色 2.5px 外圈（双层 box-shadow），替代原来的灰圈，与卡片顶条同色形成呼应 |
| 卡片 | 暖白渐变底（`#fffdf7 → #ffffff`）+ 顶部 4px accent 色条 + 圆角 16px |
| hub | 径向渐变白底（左上偏光）+ 白 3px / accent 4.5px 双描边，像旋钮 |
| 指针 | 改"纯红三角"为**水滴钉**：26×26，`clip-path` 五边形钉形，纵向渐变（亮红→accent）+ 投影 |

## 4. 三（+1）态区分

| 状态 | 类名 | 视觉 |
|---|---|---|
| 初始未转 | `.idle` | 指针上下浮动（1.4s 循环）；hub 显示"转一下"并呼吸缩放（1.8s，scale 1→1.06）；结果行灰色"还没转" |
| 正在旋转 | `.spinning` | 卡边框变 accent 色 + 黄色柔光圈；指针左右甩动（0.19s 循环，±11°）；hub 显示"…"并搏动（0.9s） |
| 已出结果 | 无（`spinning` 移除后） | 价格 pop + 金环扩散 + 彩纸炸开 + 卡片金色微光各**一次**；之后静止 |
| 已锁定 | `.locked` | 绿边框 + 绿底渐变 + 缓慢绿色光晕脉冲（2.2s 循环）；顶部色条变绿；锁定文字变绿加粗 |

三态互斥性说明：锁定 + 结果同时存在时，锁定脉冲胜出（结果类动画的选择器排除了 `.locked`），避免两组 box-shadow 动画打架。

## 5. 动效规范（全部为可实施数值）

| # | 项目 | 参数 |
|---|---|---|
| 1 | 旋转曲线 | `cubic-bezier(.16,.84,.28,1)`（沿用现有，前段快后段缓停，手感和赌博机一致） |
| 2 | 旋转时长 | **2900ms（保持不变 → JS 的 `WHEEL_SPIN_MS` 无需改）**。若 DSH 想改，必须同时改 `--wt-spin-duration`（CSS）和 `WHEEL_SPIN_MS`（JS），两处数值一致 |
| 3 | 指针 idle 浮动 | `wt-bob` 1.4s ease-in-out 无限，translateY 0→5px→0 |
| 4 | 指针转动甩动 | `wt-tick` 0.19s `cubic-bezier(.45,.05,.55,.95)` 无限，rotate 0→11°→0→−11°→0，transform-origin 50% 22%（模拟被格子打桩） |
| 5 | hub idle 呼吸 | 1.8s ease-in-out 无限，scale 1→1.06→1 |
| 6 | hub 转动搏动 | 0.9s ease-in-out 无限，scale 1→1.09→1 |
| 7 | 结果 pop（hub） | 0.5s `cubic-bezier(.34,1.56,.64,1)`（回弹曲线），scale 0.6→1.12→1，opacity 0→1 |
| 8 | 结果 pop（文字行） | 0.42s 同曲线，scale 0.7→1.10→1 + translateY 5px→0 |
| 9 | 金环扩散 | 0.7s ease-out 一次，scale 0.70→1.16，opacity 0.9→0，3px `rgba(255,199,44,.60)` 描边 |
| 10 | 彩纸 | 0.85s ease-out 一次，10 个 6px 色点从盘心炸开至半径约 40–57px 后透明消散（box-shadow 动画，纯 CSS，无 DOM/JS） |
| 11 | 中奖卡片微光 | 1.1s ease-out 一次，box-shadow 0→6px `rgba(255,199,44,.32)`→0（锁定卡不触发） |
| 12 | 锁定脉冲 | 2.2s ease-in-out 无限，box-shadow 0→5px `rgba(15,157,88,.10)`→0 |
| 13 | 「全部转起来」错落 | **280ms（保持不变 → JS 的 `i * 280` 无需改）**。四盘依次起转，第一盘停下（2900ms）时第四盘还在路上，节奏感刚好 |
| 14 | 按钮划光 | hover 时 0.35s ease，白色 45% 斜带从左扫到右 |
| 15 | 减少动态偏好 | `prefers-reduced-motion: reduce` 时关闭全部装饰动画（枚举选择器，不用 `*`），JS 旋转保留 |

触发机制说明：结果动画依赖 JS 在 spin 结束时**移除** `.spinning`——卡片从"不匹配"变为"匹配" `.wheel-card:not(.idle):not(.spinning)`，CSS 动画自动重放，**不需要 JS 加任何新类名**。这是本包零 JS 改动的原因。

## 6. 移动端建议（≤560px，两列小盘）

| 项 | 桌面 | 移动端 |
|---|---|---|
| 网格间距 | 16px | 10px |
| 卡片圆角/内边距 | 16px / 14px 12px | 13px / 10px 8px |
| 盘最大宽 | 190px | 132px |
| 外圈白边 | 6px | 5px（描边在小盘上等比减细，否则吃掉扇面） |
| hub 字号 | 12px | 10px（价格两位数仍放得下） |
| 指针 | 26×26 | 20×20（top −12px） |
| 标题图标圆片 | 26px | 22px |

再小的屏幕（<360px）不建议改单列：四盘单列会把"同时转"的对比感拆散，两列 132px 的盘仍可辨认扇形。

## 7. 接入方式与自测清单

接入：`web/index.html` 的 `</style>` 之后加一行

```html
<link rel="stylesheet" href="wheel-theme.css">
```

**自测 5 点**（接入后逐条验证，详见 CSS 文件尾注释）：

1. 表单区、结算结果区样式与接入前一致（证明无全局污染）；
2. 四张卡顶条分别为 红/琥珀/珊瑚/蓝，指针与「转」按钮同色呼应；
3. idle：指针浮动 + hub 呼吸，无布局抖动；
4. 单转与全转：转动中指针甩动，结束瞬间价格 pop + 金环 + 彩纸各一次，之后静止；
5. 锁定一盘后点「全部转起来」：该盘不动且有绿色脉冲，其余三盘正常；窗口缩到 <560px 两列不溢出。

## 8. 已知边界（如实说明）

- 本包**未接入** `web/index.html`，上述效果在接入前不会出现；
- 旋转时长与错落间隔刻意保持 2900ms / 280ms，**本包不需要改任何 JS**；
- 扇面分格颜色仍由 JS 的 `WHEEL_COLORS` 决定，四盘扇面色板相同——区分度靠外圈/指针/按钮的 accent 色，这是刻意取舍（零 JS 改动优先）；
- 彩纸是 box-shadow 动画，在低端机上与 4 个盘的 conic-gradient 同屏时若掉帧，可只删 `wt-confetti` 一段，其余动效不受影响。
