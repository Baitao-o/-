## 3. MCP 配置流程

1. 打开 <https://open.mcd.cn/mcp>；
2. 使用手机号登录；
3. 进入右上角「控制台」；
4. 点击「激活」，阅读并同意服务协议；
5. 申请并复制 MCP Token；
6. 在 WorkBuddy 的「专家·技能·连接器」→「连接器」中，进入「自定义连接器」→「配置 MCP」；
7. 填入以下配置，并把 `YOUR_MCP_TOKEN` 替换成真实 Token：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

8. 保存并启用 `mcd-mcp`，然后在对话中提出作品需求，让 AI 调用麦当劳工具。

> MCP Token 属于敏感凭据，不要提交到 Git 仓库、README、截图或 Issue 中。建议使用环境变量或连接器的安全配置保存。

## 3.1 本项目自己的 Token 配置（给使用者）

**本仓库不含任何真实 Token。** 每个使用者都要用自己的麦当劳账号申请一个：

1. 打开 <https://open.mcd.cn/mcp> → 手机号登录 → 控制台 → 激活 → 申请 Token；
2. 任选一种方式配置：
   - **网页里填（推荐）**：启动后界面顶部会有引导，粘贴保存即可；
   - 环境变量：`MCD_MCP_TOKEN=你的Token`；
   - 配置文件：复制 `mcp-config.example.json` → `~/.maimen-budget-meal/config.json`。

Token 只保存在本机用户目录，已加入 `.gitignore`；界面与日志只显示掩码。

验证：`curl -s http://127.0.0.1:8808/api/config`，`source` 为 `file` 或 `env` 即正常。

## 6. 主要能力（麦门省钱搭子）

- **预算点餐**：给人数和预算，输出 2~3 套可解释的方案（最省钱 / 均衡饱腹 / 丰富尝鲜）；
- **结构配餐求最低价**：指定主食/小吃/甜品/饮品各几份，系统在满足全部份数下求实付最低组合，真实算价校准菜单价与成交价的差异；
- **想吃优先**：可以点名想吃什么（如「鸡翅」「甜品」），系统会在预算内优先安排；如果本店没有这个商品，会直接告诉你（并说明不是预算问题）而不是让你白提高预算；如果为满足偏好比最低价贵，会如实写出差额；
- **忌口硬约束**：忌口和不辣要求命中的商品直接排除，任何方案都不会出现；
- **如实拒绝**：预算内配不齐时，明确给出最低所需金额和差额，不硬凑超预算方案；
- **🎰 美食转盘**：四个品类盘（主食/小吃/甜品/饮品）随机抽，抽到什么算什么，最后调 `calculate-price` 给出真实实付金额；满意的盘可锁定后只重转其他几个；
- **网页 + 命令行双入口**：双击 `start.cmd`（或 `python web/server.py`）即可打开零依赖网页界面，端口被占用会自动切换，与命令行共用同一套规划逻辑；
- 详实记录见 `docs/USAGE.md`（使用说明）与 `docs/RUN_RECORD.md`（实跑证据）。
